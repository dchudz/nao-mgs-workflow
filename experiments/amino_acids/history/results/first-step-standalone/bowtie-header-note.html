Bowtie2 header reproducibility

A controlled replay of eight outcome-selected read pairs changed human-filter retention when only FASTQ header format changed. Sequences, qualities and record order were identical. Each format was run twice with explicit Bowtie2 seed 0.

The space form exactly matches the native SAM-to-FASTQ roundtrip. Results and alignment multisets were stable within each format across both repeats. Bowtie2 documents read-name-dependent pseudo-random initialization, consistent with this observation. Bowtie2 documentation.
